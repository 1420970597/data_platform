# 受控领域长链推理模型训练数据制备方法论

**版本**：0.1
**日期**：2026-09-08
**适用对象**：经授权的受控领域知识问答、文档理解、图文/表格理解、规范核验与研究辅助模型训练项目。

## 1. 摘要与边界

本方法论面向“领域长链推理模型”的训练数据制备，覆盖文本、文档图像、表格、图文配对等多模态数据，并支持两个训练阶段：

1. **阶段 A：领域继续预训练或监督适配，采用 LoRA 实现参数高效训练。**
2. **阶段 B：后训练，采用 GRPO 或同类可验证奖励优化。**

术语说明：LoRA 是参数高效适配方法，而不是从零开始的预训练范式。本文将需求中的“预训练（LoRA）”规范为“领域继续预训练和/或监督适配，使用 LoRA 降低训练与版本成本”。

“以最小代价最高销量”在本文中按“**以最低全生命周期成本获得最高可用训练数据质量和可复用产出**”理解。其评价对象不是原始样本数量，而是对冻结评测集带来的有效增益、合规可用性和可维护性。

### 1.1 强制安全与合规范围

“军事领域”仅可理解为具备明确授权、已公开或已完成脱敏与审查的非敏感领域知识。系统不得接入、生成、保留或训练以下内容：

- 作战、目标选择、兵力部署、战术行动、武器使用、实时态势或行动方案；
- 未公开技术参数、保密资料、受控装备数据、未授权内部资料；
- 个人信息、可识别个人的轨迹或通信内容，以及无法证明授权链的数据；
- 任何可能直接提升现实伤害、规避监管或未经授权情报活动能力的任务样本。

平台的定位是**受控知识处理与模型数据治理**，不是作战决策、目标识别、行动规划或实时指挥系统。

### 1.2 北极星指标

采用“价值增益优先”的决策指标：

`数据批次价值 = 冻结评测集增益 / 全生命周期成本`

全生命周期成本包括采集、授权核验、预处理、标注、人工复核、存储、训练、审计与撤回成本。任何候选数据在进入训练集前必须先通过以下硬门槛：

- 来源、授权/许可、获取时间、处理链和责任人均可追溯；
- 通过敏感信息、隐私、版权与用途限制检查；
- 与验证集、测试集及其近重复样本完成隔离；
- 可由样本 ID 追溯到源文档和全部转换版本；
- 通过该数据类型对应的质量检查，不以“数量大”替代质量证明。

## 2. 调研结论及设计含义

| 调研发现 | 原始证据 | 设计含义 |
|---|---|---|
| LoRA 冻结基座模型并训练低秩增量，可显著降低可训练参数、训练显存和多版本存储成本；合并权重后不增加推理延迟。 | Hu et al., *LoRA*, https://arxiv.org/abs/2106.09685 | 用“共享基座 + 分领域 LoRA + 数据/模型一一绑定”替代重复保存全量模型；优先将预算投入数据质量和评测。 |
| 高质量领域语料可通过“分类器召回 - 人工核验漏召回 - 重训分类器”的迭代方式构建，并必须进行去污染。 | Shao et al., *DeepSeekMath*, https://arxiv.org/abs/2402.03300 | 建立小规模种子集、主动抽检和迭代召回闭环；训练集制作前执行评测集 n-gram 与近重复隔离。 |
| GRPO 以同一提示的多候选组内相对奖励估计优势，可减少 critic 训练成本；奖励可靠性成为训练成败关键。 | Shao et al., *DeepSeekMath*, https://arxiv.org/abs/2402.03300 | GRPO 数据包必须携带提示、候选、可复验奖励证据、组内归一化信息和版本化验证器。 |
| 对复杂推理，过程级反馈能比仅终局反馈更精确；主动学习能将人工标注投向高价值不确定样本。 | Lightman et al., *Let's Verify Step by Step*, https://arxiv.org/abs/2305.20050 | 采集“证据引用、步骤检查点、错误定位、最终结论”而非只采集答案；人工只复核模型分歧和高风险样本。 |
| 在固定训练预算下，严格筛选的较小多模态数据集可优于未筛选的大池；小规模试验可指导大规模筛选策略排序。 | Gadre et al., *DataComp*, https://arxiv.org/abs/2304.14108 | 用固定基座、固定预算和冻结评测集做低成本筛选 A/B；以“数据策略排名”而非一次性大规模训练决策。 |
| 生成式 AI 数据治理应覆盖来源历史、版权、隐私、上线门槛、持续监测及治理责任。 | NIST AI RMF / AI 600-1, https://doi.org/10.6028/NIST.AI.600-1 | 源数据账本、数据卡、风险分级、Go/No-Go 审批、审计日志、撤回和再评估是平台原生能力。 |

## 3. 总体路线

```mermaid
flowchart LR
  A[授权/公开源登记] --> B[采集与不可变原件存档]
  B --> C[文本化/OCR/版面与表格解析]
  C --> D[隐私/版权/敏感用途筛查]
  D --> E[去重、近重复与质量评分]
  E --> F[多模态对齐与事实证据切片]
  F --> G[主动抽检、人工复核与标注]
  G --> H[训练样本构造]
  H --> I[评测隔离与数据版本冻结]
  I --> J[LoRA 数据包]
  I --> K[GRPO 提示-候选-奖励包]
  J --> L[训练与评估]
  K --> L
  L --> M[审计、监测、撤回与回流]
```

路线遵循五个原则：

1. **先合法可用，后规模化。** 无授权、无法追溯、无法撤回的数据不进入候选池。
2. **先证据化，后生成化。** 合成样本必须锚定已批准的源片段，不以无来源的模型文本扩充知识库。
3. **先小样本筛选，后大批量生产。** 固定训练预算的小型代理实验决定策略是否放大。
4. **先自动化过滤，后人工处理不确定性。** 人工预算只用于模型分歧、低置信、多模态冲突和高风险边界样本。
5. **先隔离评测，后训练。** 评测污染一旦发现，训练批次和评测结论同时失效，必须可重建。

## 4. 数据资产分层与数据契约

### 4.1 数据层级

| 层级 | 内容 | 进入下一层的门槛 |
|---|---|---|
| L0 原件层 | 已登记来源的文档、图像、表格、公开网页快照及其哈希 | 来源、许可、用途、保留期完整；原件不可修改。 |
| L1 规范化层 | 文本、OCR、版面块、表格结构、媒体元数据、语言与时间标签 | 解析成功率、文本质量、文件完整性、隐私初筛合格。 |
| L2 候选知识层 | 去重后的段落、图文对、表格单元、跨文档证据组 | 相似度去重、语义质量、图文一致性、敏感风险门槛合格。 |
| L3 监督层 | 指令样本、结构化抽取、引用问答、对比、纠错、过程检查点 | 任务模板、证据引用、标注共识、样本难度与覆盖度均衡。 |
| L4 奖励层 | GRPO 提示、候选轨迹、规则/人工奖励、负例、验证证据 | 奖励可复验、验证器版本固定、候选组完整、风险审查通过。 |
| L5 评测层 | 验证集、测试集、红队集、回归集 | 与 L0-L4 的文本、图像、语义近重复均隔离。 |

### 4.2 每条样本的最小数据契约

每条可训练样本至少包含：

```text
sample_id, dataset_version, source_ids, source_license, permitted_use,
raw_hash, transform_lineage, modality, language, sensitivity_tier,
content_hash, duplicate_cluster_id, quality_scores, task_template_id,
evidence_spans, label_or_reward, reviewer_status, created_at, expiry_or_review_at
```

禁止将“来源不明”“许可未知”“处理链缺失”“敏感等级未判定”的样本导出为训练数据。

## 5. 阶段 A：LoRA 领域继续预训练与监督适配数据

### 5.1 数据目标

阶段 A 的目标是建立受控领域的术语覆盖、文档结构理解、证据引用、跨模态理解和稳定指令遵循能力。优先制备以下非行动化任务：

- 经授权规范、教材、公开研究资料的定义解释与版本差异比对；
- 长文档摘要、结构化字段抽取、表格还原、图文一致性检查；
- 基于已给证据的问答、引用定位、冲突陈述识别与不确定性表达；
- 多文档事实核对、标准条款映射、格式转换和审阅辅助。

### 5.2 数据构成

| 子集 | 作用 | 建议制备方法 |
|---|---|---|
| 领域语料 | 继续预训练，补足术语和文体覆盖 | 从 L2 选择高质量去重文本、表格序列化文本、图像说明；保留原始结构标记。 |
| 证据型指令样本 | 监督适配，提升可引用回答 | 基于 L2 证据片段构造“问题 - 证据 - 结构化答案 - 引用”四元组。 |
| 结构化任务样本 | 处理表格、表单、图表、文档版面 | 用规则模板从 L1/L2 自动生成，再做一致性校验。 |
| 纠错和拒答样本 | 降低臆造与越界 | 将证据不足、来源冲突、用途受限样本转为“说明不确定性/拒绝处理”的正例。 |
| 多模态样本 | 处理图文、表格、扫描件 | 以源页、OCR、版面块、结构化表格和人工复核摘要形成绑定对象。 |

### 5.3 低成本高质量做法

1. **种子集优先。** 用少量专家核准的高质量样本训练轻量分类器/质量判别器，先确定“值得收”的模式。
2. **结构化自动生产。** 文档标题、章节、表头、单位、引用、版本号、图注等可由解析器生成弱标签；仅把冲突与异常交给人工。
3. **困难样本挖掘。** 选择分类器低置信、OCR 与原图不一致、图文语义不匹配、多个模型答案冲突的样本复核。
4. **小规模代理训练。** 固定基座、LoRA 目标层、训练 token 数和评测集，对不同过滤策略做可复现实验；只放大排名领先的策略。
5. **领域模块分离。** 对术语、格式或用途边界差异大的子领域维护独立数据版本和 LoRA 适配器，避免以混合数据掩盖冲突。

### 5.4 LoRA 数据包

每个训练运行输出不可变清单：

```text
base_model_version
adapter_config (target_modules, rank, alpha, dropout)
dataset_manifest_hash
sample_count and token_count
train/validation/test split hashes
preprocessing and truncation policy
quality_gate_report
evaluation_report
approver and approval_time
```

## 6. 阶段 B：GRPO 后训练数据

### 6.1 设计目标

GRPO 阶段不应把“长文本”直接等同于“高质量推理”。应优化可验证的输出行为：证据充分、事实一致、结构完整、能够指出不确定性、遵守用途边界。

训练对象为**可审计推理摘要和中间证据检查点**，而不是收集或暴露不可审计的内部思维过程。每个样本都应允许第三方依据原始证据复核。

### 6.2 GRPO 数据单元

```text
prompt_id
prompt_text_or_multimodal_input
allowed_context_ids
candidate_group_id
candidate_outputs[]
verifier_outputs[]
reward_vector (evidence, correctness, structure, safety, style)
scalar_reward
reward_evidence
reference_policy_version
verifier_version
human_override_if_any
```

### 6.3 奖励函数

采用向量奖励而非单一“好/坏”标签：

`R = w1*证据可追溯 + w2*事实/逻辑可验证 + w3*结构完整 + w4*边界遵守 + w5*表达质量 - 违规惩罚`

其中，边界遵守、隐私、版权和敏感用途风险为硬约束：一旦触发，样本不参与正向强化；必要时进入拒答/升级人工复核集。

### 6.4 验证器优先级

1. **确定性规则验证器：** JSON/表格 schema、引用存在性、单位格式、证据位置、禁止类别命中。
2. **可执行一致性验证器：** 表格计算复算、文档版本号比对、摘要是否覆盖指定段落。
3. **基于证据的判别器：** 回答是否被指定证据支持、图文是否一致、是否遗漏冲突。
4. **人工裁决：** 只处理验证器分歧、难例、模型高不确定性或高风险样本。

GRPO 不能依赖不可解释的单一奖励模型。每一轮奖励必须保存验证器证据和版本，以支持回放、漂移分析和撤回。

## 7. 多模态数据制备

### 7.1 统一表示

每个文档页或图文对以“内容对象”而不是孤立文件管理：

```text
asset_id -> raw_file -> rendered_page/image -> OCR tokens -> layout blocks
         -> table/chart structure -> caption -> source reference -> quality/risk scores
```

对扫描件需同时保存：原图哈希、OCR 版本、版面模型版本、表格解析版本和人工修订记录。任何修订都创建新版本，不能覆盖原件。

### 7.2 多模态质量门

- 图像清晰度、分辨率、页面完整性、旋转和裁切检测；
- OCR 字符置信度、版面阅读顺序、表格单元准确度；
- 图文相似度与标题/图注一致性；
- 视觉近重复、文本近重复、跨模态重复簇；
- 版权/授权、人物与个人信息检测、敏感内容分类；
- 同一事实在文本、表格、图中出现冲突时标为待复核，不自动合并。

## 8. 成本最小化机制

### 8.1 成本分层

| 成本层 | 首选办法 | 人工介入条件 |
|---|---|---|
| 获取与授权 | 白名单来源、许可模板、批量元数据登记 | 许可不清、用途限制冲突、来源变更。 |
| 文本化与解析 | 批处理 OCR、规则/版面模型、缓存复用 | OCR 低置信、表格结构损坏、原件缺页。 |
| 质量控制 | 哈希、近重复、语言/长度/结构规则、轻量打分 | 多模型分歧、低置信、稀有高价值模式。 |
| 标注 | 模板弱标注、验证器自检、主动学习 | 高影响错误、证据冲突、规则无法验证。 |
| 合成 | 受证据约束的候选生成、自动验证、拒绝采纳无证据输出 | 验证器无法判定或候选质量接近阈值。 |
| 训练评估 | 小规模代理实验、数据版本对照、冻结评测 | 策略放大决策、异常收益或回归。 |

### 8.2 预算分配规则

- 先为源数据台账、评测隔离、核心验证器预留固定预算；这是不可削减的质量底座。
- 对每一类候选数据计算“每千元带来的冻结评测增益”和“单位人工复核后的接受率”。
- 当某一策略连续两个版本未带来显著增益，停止扩量，转向错误分析或更换筛选特征。
- 合成数据不得按产量计功；只计入通过证据、去重、验证器和抽检四重门槛的样本。

## 9. 质量、合规与版本治理

### 9.1 必须可量化的指标

| 维度 | 指标 | 说明 |
|---|---|---|
| 可追溯 | 来源/许可/处理链完整率 | 目标为 100%，缺失即阻断导出。 |
| 安全合规 | 禁止类别漏检数 | 目标为 0；发现后触发批次隔离与复盘。 |
| 去重 | 精确重复率、近重复率、跨分割重叠率 | 训练-评测间已确认重叠目标为 0。 |
| 多模态 | OCR 置信分布、图文对齐通过率、表格结构正确率 | 分类型设门槛，门槛来自人工黄金集。 |
| 标注 | 双人一致率、仲裁率、主动学习接受率 | 用于判断人工投入是否有效。 |
| 训练收益 | 每数据版本的冻结评测增益、回归数量 | 对照同一基座和同一训练预算。 |
| 成本 | 每通过样本成本、每千 token 成本、每评测点成本 | 以全生命周期成本核算。 |
| 可维护性 | 撤回定位时长、重建时长、版本可复现率 | 样本撤回应能定位影响的数据包和模型版本。 |

### 9.2 发布门禁

训练数据版本只有同时满足以下条件才可发布：

- 完成许可、用途、隐私和敏感风险检查；
- 完成训练/验证/测试隔离；
- 质量报告、样本清单、变换链、验证器版本均已冻结；
- 通过抽检计划与责任人审批；
- 具备撤回、再构建和模型影响追踪方案。

## 10. 最小可行验证计划

1. 建立一个仅含已授权、非敏感文档的 L0 种子库及黄金评测集。
2. 在固定基座和固定 LoRA 预算下，对“无筛选、规则筛选、分类器筛选、分类器加人工主动复核”做小规模对照。
3. 选择在质量、成本、评测增益三项中排名最优的策略，扩展至文本、扫描文档和表格三类数据。
4. 构建最小 GRPO 数据包：提示、多个候选、规则验证器、证据评分、人工仲裁记录。
5. 通过全链路回放验证：从一个模型输出可追到数据包、样本、源文档、许可、变换和审批记录。
6. 仅在所有门禁通过后，扩大数据规模与适配器数量。
