## 0. 建设目标与执行边界

建设一套可在内网或受限网络部署的军事领域训练数据制备系统，服务于战前训练与战备准备、战时保障记录、战后复盘、联合演训、多军兵种/专业条线以及有人、无人和有人/无人协同平台资料的数据治理。

系统产出是可追溯、可验证、可撤回的 LoRA/监督适配数据包和 GRPO 数据包。系统只处理经授权、公开或完成脱敏审查的资料，不生成目标选择、武器运用、战术行动、部署、指挥控制或自主行动指令。

执行规则：

- 所有任务必须关联需求 ID、数据契约版本、代码提交和验收证据。
- 未完成来源授权、用途审查、场景标签和撤回设计，不得导入真实资料。
- 战时资料只用于授权的保障、维修、医疗、通信、归档和复盘任务；不改变系统安全边界。
- 自动化处理确定性工作；阶段归属、军兵种冲突、有人/无人协同边界和高风险样本由人工审核。
- 任何疑似高风险输入默认隔离，保留最小审计信息，不进入训练导出。

状态标记：`[ ]` 未开始，`[~]` 进行中，`[x]` 已完成，`[!]` 阻塞/需决策。

|---|---|---|---|

| P4 审核与样本 | 场景标签、证据片段、主动审核、监督样本和合成谱系 | P3 | 样本可由证据重建并完成双人/仲裁流程 |

| P7 GRPO 数据闭环 | 候选组、验证器、RewardSpec、回放和导出 | P5 | episode 100% 可回放 |

依赖原则：先治理和数据模型，再建设流水线；先完成小规模黄金集闭环，再接入规模化数据；任何阶段均不得绕过授权、审计、评测隔离和撤回能力。

## 13. Definition of Done

- [ ] 需求 ID、设计章节、API/schema、数据库迁移和代码已关联。

- [ ] 能在离线环境构建，或明确记录经过批准的外部依赖。
- [ ] 有回滚、撤回、重建和数据影响处理。

## 14. 发布前 Go/No-Go

### Go 条件

- [ ] 来源、许可证、允许用途、保留期和责任人完整率 100%。
- [ ] 发布快照中未授权、过期、撤回和隔离资产为 0。
- [ ] 训练与评测确认重叠为 0，且三层污染检测有证据。
- [ ] PII 高敏/低置信自动放行为 0。
- [ ] 数据包血缘完整率、LoRA 重建一致率、GRPO episode 回放率均达到 100%。
- [ ] 场景覆盖报告已审阅，缺口和不适用组合已记录。
- [ ] 审计、撤回、灾备、权限、供应链和离线部署演练通过。

### No-Go 条件

- [ ] 存在未授权来源、用途冲突、未处理撤回或过期资产。
- [ ] 存在评测污染、PII 高敏自动放行、测试标签泄漏或审计链缺失。
- [ ] 场景标签缺失、跨军兵种证据冲突未仲裁、有人/无人交接记录无法复核。
- [ ] RewardSpec/验证器不可回放、奖励漂移失控或训练包不可重建。
- [ ] 无法在受控网络中证明数据出口、远程服务和临时文件行为。
